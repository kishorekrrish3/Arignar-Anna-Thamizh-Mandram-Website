This website presents Arignar Anna Thamizh Mandram's activities and identity at VIT Chennai. It brings together information about the organization, events, team, gallery, literary content, achievements, and ways to get in touch.

## Website sections

- **About the mandram** — mission and community identity
- **Events and cultural programming**
- **Pongal feature**
- **Team and member information**
- **Gallery**
- **Kanaiyazhi literary section**
- **Achievements**
- **Contact**

## Tech stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS and component-based UI
- Supabase integration, as configured by the application

## Run locally

### Requirements

- Node.js compatible with the version in `package.json`
- npm

```bash
git clone https://github.com/kishorekrrish3/Arignar-Anna-Thamizh-Mandram-Website.git
cd Arignar-Anna-Thamizh-Mandram-Website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Content and deployment notes

Review event dates, member information, photographs, and contact details before publishing updates. Keep any Supabase credentials in environment variables and configure access policies before using real user data.

## Contributing

Content corrections, accessibility improvements, and focused bug fixes are welcome. Please respect the organization’s identity and obtain permission before publishing personal information or photographs.
